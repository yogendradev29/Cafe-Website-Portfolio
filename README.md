The Pink City Roasters
A premium, mobile-first cafe website concept for The Pink City Roasters, an artisanal coffee shop based in Jaipur, Rajasthan. The design focuses on warm hospitality, premium coffee culture, elegant visuals, and smooth user experience for young professionals, students, and coffee enthusiasts.

Live Preview
Open the project locally:

python -m http.server 4174
Then visit:

http://localhost:4174
Project Overview
This is a complete frontend landing website built as a single-page experience for a premium local cafe. It includes a sticky glassmorphism navbar, immersive hero section, about section, menu cards, gallery, testimonials, contact details, Google Maps embed, and a floating WhatsApp order button.

The goal of this project is to demonstrate clean frontend development, modern UI/UX design, responsive layout skills, and business-focused web design suitable for a freelance portfolio.
